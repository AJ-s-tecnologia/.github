
# Como contribuir

Obrigado por querer contribuir! Cada projeto pode ter particularidades,
mas o fluxo geral é este:

## Fluxo de contribuição
1. Faça um fork do repositório desejado
2. Crie uma branch: `git checkout -b feat/minha-feature`
3. Siga o padrão de commits: `tipo: descrição curta` (ex: `fix: corrige bug no login`)
4. Abra um Pull Request explicando o que mudou e por quê
5. Aguarde a revisão — CI precisa passar antes do merge

## Requisitos por stack
- **Node.js**: rode `npm install` e `npm test` antes do PR
- **Python**: use `venv`, rode `pytest` e siga PEP8
- **PHP**: siga PSR-12 e rode os testes do PHPUnit

## Antes de abrir uma issue
Verifique se já não existe uma issue parecida.
